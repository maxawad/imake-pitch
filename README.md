# iMake Pitch

iMake Pitch is a one-page "coming soon" site for iMake, a startup idea whose pitch deck was not yet published. It shows the iMake name, a "Pitch Deck Coming Soon" message and a contact link for questions.

## What it does

- Shows a dark, centered landing page with the iMake name and a coming soon notice.
- Adapts to phone and desktop screens.
- Offers a tap-to-call contact button for questions.

## Tech stack

Plain HTML and inline CSS in a single file, `index.html`. There are no dependencies, no build step, no JavaScript and no API keys.

## Run it

Open `index.html` in any browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Live demo

The repository is already static files, so it can be hosted as is on GitHub Pages, Netlify, Vercel or any static host. Publish the repository root, with no build command.
